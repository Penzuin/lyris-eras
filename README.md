# Lyris Era Tracker

The page for managing Lyris Voxel's ideas across its eras and systems.

This repo is public, but it holds no ideas. The page loads the list from the
private game repo (`design/eras.json`) with your own GitHub token, which is
stored only in your browser, and saves edits back there as commits.

Live at https://penzuin.github.io/lyris-eras/
